# Проверка сборки

Дата: 1 октября 2026 года.

| Проверка                                  | Результат                                  |
| ----------------------------------------- | ------------------------------------------ |
| TypeScript `npm run check`                | Успешно                                    |

Тесты проверяют HTTP-обработчики и SQL, включая конкурирующие запросы, но PGlite выполняет транзакции последовательно. Запустить обычный PostgreSQL в текущей среде не удалось: он не работает от root, а смена системного пользователя запрещена средой. Поэтому тестирование драйвера `pg` с реальным многосоединённым сервером и запуск Docker Compose здесь не выполнены.

Команда для такой проверки на вашей машине:

```bash
TEST_DATABASE_URL=postgres://USER:PASSWORD@localhost:5432/TEST_DATABASE npm test
```

Проверка внешних SMS/банковских сервисов не проводилась: они не подключены. Сейчас адаптеры изолированы в режиме разработки, запуск production запрещён. Проверка полного клиентского мобильного UI не проводилась: проект содержит сервер и техническую админку.
